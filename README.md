# وَمْضة

واجهة بسيطة للجوال والكمبيوتر، مع وضع فاتح وداكن. واجهة وأسئلة بالعربية، مع اتجاه من اليمين إلى اليسار.

اللعبة 3 جولات، كل جولة 5 أسئلة ومدة السؤال 20 ثانية. الإجابة الصحيحة بنقطة، والنقاط تراكمية. تظهر الإجابة الخاطئة بالأحمر والصحيحة بالأخضر. بعد إجابة الجميع أو انتهاء الوقت، يضغط المضيف «السؤال التالي»، أو «عرض نتائج الجولة» بعد السؤال الخامس. تظهر لوحة النتائج بين الجولات فقط، ويبدأ المضيف الجولة التالية.

## التشغيل

افتح Terminal داخل مجلد المشروع، ثم شغّل:

```bash
npm install
npm start
```

افتح `http://localhost:3000` في المتصفح. لا تفتح `public/index.html` مباشرة؛ اللعب الجماعي يحتاج الخادم.

إذا كانت نسخة أخرى تعمل على المنفذ 3000، أوقفها أولًا باستخدام Ctrl+C. لو ظهر التصميم القديم، حدّث الصفحة باستخدام Ctrl+Shift+R.

بعد تعديل `server.js` أعد تشغيل الخادم؛ تحديث المتصفح وحده لا يحدّث الأسئلة أو قواعد اللعبة الموجودة في ذاكرة الخادم. للتحقق من النسخة افتح `http://localhost:3000/api/version`؛ يجب أن تظهر `wamda-rounds-v1` مع 3 جولات و5 أسئلة ومدة 20 ثانية.

## الواجهة

- تصميم بعمود واحد وأزرار مناسبة للمس، مع عرض محدود ومريح على الكمبيوتر.
- زر الوضع الفاتح / الوضع الداكن أعلى كل شاشة. يبدأ بمظهر الجهاز، ويحفظ اختيار المستخدم في المتصفح عند تغييره.
- خط «تجوال» مستضاف محليًا بوزنين، وترخيصه في `public/fonts/OFL.txt`.
- في نتائج الجولة الأولى يبدأ اللاعبون بأصفار بترتيب أبجدي عربي، ثم تزيد النقاط والصفوف ثابتة، وبعدها تتحرك مرة واحدة بسلاسة إلى مراكزها. عند تفعيل تقليل الحركة تظهر النتائج مباشرة.
- نسخ كود الغرفة وإظهار عدد اللاعبين، مع زر لمغادرة غرفة الانتظار.
- تظهر الإجابة الخاطئة بالأحمر والصحيحة بالأخضر، بما يشمل مربعات A وB وC وD، دون رسالة تصحيح نصية.
- عند تساوي النقاط تظهر مراكز متساوية، دون تغيير حساب النقاط.
- عند فقد الاتصال يرجع اللاعب إلى الصفحة الرئيسية، لأن الخادم الأصلي لا يستعيد عضوية الغرفة بعد إعادة الاتصال.

## الملفات

- `public/index.html`: الشاشات.
- `public/style.css`: التنسيق المتجاوب وألوان الوضعين.
- `public/theme.js`: تبديل المظهر وحفظه، قبل تحميل التنسيق لتجنب ظهور المظهر الخطأ أولًا.
- `public/app.js`: أحداث الواجهة واتصال Socket.IO.
- `server.js`: الخادم والأسئلة وإدارة الجولات وصلاحيات المضيف.

## الاختبارات

لتشغيل الاختبارات تحتاج Node.js 22 أو أحدث. تستخدم الاختبارات منفذًا مستقلًا تلقائيًا:

```bash
npm test
```

يوجد 12 اختبارًا، تشمل مباراة كاملة بعميلين حقيقيين عبر Socket.IO، انتهاء وقت السؤال، انتقال الاستضافة، وحفظ المظهر. اختبارات الواجهة تستخدم بديلًا مبسطًا لـDOM؛ ليست اختبارات عرض داخل متصفح.

تم التحقق في متصفح محلي على عرض 390 بكسل من ألوان الخيارات وحركة ترتيب النتائج، مع معاينة الوضعين الفاتح والداكن. اختبارات الواجهة تغطي العد من الصفر والترتيب الأبجدي والتعادل وإلغاء الحركة عند بدء السؤال التالي.

مجلد `node_modules` غير مضمن في الأرشيف؛ ينشئه `npm install`. لم تُضف حزم تشغيل جديدة.
