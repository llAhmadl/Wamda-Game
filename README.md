# وَمْضة

**وَمْضة** لعبة أسئلة عربية جماعية تعمل مباشرة من المتصفح. ينشئ المضيف غرفة، ينضم اللاعبون باستخدام رمز الغرفة، ويتنافسون في جولتين بنظام يعتمد على سرعة وصحة الإجابة.

## المميزات

- لعب جماعي لحظي باستخدام **Socket.IO**
- غرف خاصة مع صلاحيات للمضيف
- أكثر من نظام لاحتساب النقاط
- تصنيفات وبنوك أسئلة قابلة للإدارة
- لوحة مطور لإدارة الأسئلة والتصنيفات
- واجهة عربية متجاوبة مع الجوال والكمبيوتر
- وضع فاتح وداكن
- تخزين دائم للبيانات باستخدام **PostgreSQL**

## التقنيات

**Node.js · Express · Socket.IO · PostgreSQL · HTML · CSS · JavaScript**

## التشغيل محليًا

يتطلب **Node.js 22+**.

```bash
git clone https://github.com/llAhmadl/wamda.git
cd wamda
npm install
npm start
```

ثم افتح:

```text
http://localhost:3000
```

لتشغيل الاختبارات:

```bash
npm test
```

## الإعداد

المتغيرات الاختيارية موضحة في `.env.example`. لا ترفع ملف `.env` أو أي بيانات اتصال خاصة إلى GitHub.
